🐙 Publicar no GitHub Pages

Publique seu painel financeiro online gratuitamente em 3 passos com o GitHub

🚀 Hospedagem Gratuita & Global • 100% Autônomo • Sem Configurações Complexas

Arquivo do Repositório: index.html

O GitHub Pages necessita do arquivo com o nome exato index.html na raiz do repositório para carregar sua página inicial automaticamente.

1
Crie o Repositório no GitHub

Acesse github.com/new, defina um nome para o seu projeto (ex: painel-financeiro) e deixe-o marcado como Public.

2
Envie o Arquivo index.html

Na página do repositório recém-criado, clique em "uploading an existing file" e envie o arquivo index.html baixado no botão acima. Clique no botão verde Commit changes.

3
Ative o GitHub Pages

No menu superior do repositório, clique em Settings > selecione Pages no menu lateral esquerdo > em Branch, escolha main e pasta / (root) > clique em Save.

🌐 Endereço Público do seu Site:
https://<seu-usuario>.github.io/<nome-do-repositorio>/
